A single deadpan weather forecast for an invented city, written by `main.py`
to `entry.txt` (156 characters, within the 160-character limit).

> In Lower Brindlewick, expect 41 degrees and a light drizzle that falls upward after 3 p.m., confusing the pigeons and delaying the 4:12 bus by nine minutes.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else.
